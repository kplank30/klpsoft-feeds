# klpsoft Feeds for WooCommerce

**klpsoft Feeds** is a lightweight, high-performance product export plugin for WooCommerce. Automatically generate and stream optimized product feeds for Google Merchant Center, Bing Shopping, and Idealo to maximize your e-commerce reach and marketing visibility.

## 🚀 Installation & Setup

### Via the WordPress Dashboard (Recommended)
1. Navigate to your WordPress Admin area and go to **Plugins > Add New**.
2. Search for **"klpsoft Feeds"**.
3. Click **Install Now** and then **Activate**.

### Manual Installation via GitHub / FTP
1. Download this repository as a `.zip` file.
2. Extract the folder and rename it to `klpsoft-feeds`.
3. Upload the folder to your `/wp-content/plugins/` directory via FTP.
4. Activate the plugin through the WordPress **Plugins** menu.
